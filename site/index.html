DockWizard

Save your Dock as a preset. Move it between Macs. Edit it in bulk.

Presets that travel

Apps are matched by bundle identifier with a verified path, and $HOME becomes ~, so a preset from your work Mac still finds ~/Downloads on your laptop. Anything not installed is reported, never silently dropped.

Bulk editing

Multi-select, drag a whole block to reorder, wrap a run of apps in spacers, or extract a selection into a new preset. Nothing touches the Dock until you press Apply.

Scriptable

The app bundles a dockwizard CLI with real exit codes — 2 means applied with items skipped — so a new-Mac setup script can set up your Dock and tell you what was missing.

Always reversible

Every apply snapshots the entire Dock preference domain first. dockwizard restore puts it back, including keys DockWizard doesn't even model.

Install

brew install --cask bevanjkay/tap/dockwizard

or download the DMG above and drag DockWizard to Applications. To use the command line tool, open Settings → Command Line Tool → Install.

DockWizard isn't on the Mac App Store and can't be: a sandboxed app is not allowed to write another application's preferences, which is the entire job.
